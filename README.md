# Basma Seif — AI Video Creator Portfolio

A responsive, single-page portfolio website with 13 selected video projects, pink/purple visual styling, category filters, and an in-page video player.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it.

## Publish with GitHub Pages
1. Create a new public repository on GitHub (for example, `basma-portfolio`).
2. Upload **all files and folders inside this package** (not the outer ZIP file).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. GitHub will provide the published website URL after deployment.

The email contact is set to `basmaseif29@gmail.com`. Replace it in `index.html` if needed.
